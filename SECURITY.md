# Política De Segurança

## Versões Suportadas

Cada projeto recebe correções apenas na branch padrão (a versão mais recente do código).

## Como Reportar Uma Vulnerabilidade

**Não abra uma issue pública** para falhas de segurança.

Envie a descrição para o líder da turma dona do projeto ou para o e-mail origenes.lessa.ds@gmail.com, informando:

- o que foi encontrado e onde (arquivo, rota, tela)
- passos para reproduzir
- impacto esperado
- sugestão de correção, se houver

## Prazo De Resposta

Esse é um projeto escolar mantido por alunos. Respondemos o mais rápido possível, em geral em poucos dias.

## Boas Práticas

- Nunca versione `.env`, senha, hash, token ou chave de API.
- Se um segredo vazou, troque-o imediatamente e avise o líder da turma.
- Mantenha as dependências atualizadas.
