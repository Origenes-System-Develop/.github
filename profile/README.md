## 🧭 Como a organização funciona

<table>
<tr>
<td width="50%" valign="top">

**👥 Uma turma, um time**<br>
Cada turma tem o seu time (<i>team</i>) e os seus repositórios.

</td>
<td width="50%" valign="top">

**🧭 Um líder por turma**<br>
O líder gerencia os repositórios e a sala dele.

</td>
</tr>
<tr>
<td valign="top">

**👀 Todos veem tudo**<br>
Qualquer aluno pode ler e aprender com os projetos de todas as turmas.

</td>
<td valign="top">

**✏️ Edita quem é da turma**<br>
Só a turma dona do projeto altera o código dele. As outras leem, clonam e estudam.

</td>
</tr>
</table>

<details>
<summary><b>🧑‍💻 Sou da turma, por onde começo?</b></summary>

<br>

1. Aceite o convite e confira se você está no time da sua turma.
2. Clone o repositório do projeto e crie uma branch a partir da branch padrão:

~~~bash
git clone https://github.com/Origenes-System-Develop/<repositorio>.git
git checkout -b feature/nome-da-funcionalidade
~~~

3. Faça commits curtos no padrão `feat: …`, `fix: …`, `docs: …`.
4. Abra um **Pull Request** explicando o que mudou e por quê.
5. O **líder da turma** revisa e aprova antes do merge. Não há push direto na branch padrão.

Detalhes no [guia de contribuição](https://github.com/Origenes-System-Develop/.github/blob/main/CONTRIBUTING.md).

</details>
